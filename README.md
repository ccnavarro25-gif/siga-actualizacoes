# Actualizações do SIGA

Este repositório guarda as versões novas do **SIGA — Sistema Integrado de Gestão Administrativa**, da **CCM Soluções Administrativas**.

O SIGA (computador e telemóvel) vê aqui, sozinho, se há versão nova e actualiza-se.
Cada versão vem com um ficheiro de controlo assinado pela CCM; o SIGA recusa qualquer ficheiro que não tenha essa assinatura.

Não há aqui código do SIGA nem dados de clientes.
